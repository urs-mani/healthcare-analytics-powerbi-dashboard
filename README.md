# 🏥 Healthcare Analytics Dashboard

### Power BI | DAX | Data Visualization | Healthcare Analytics

A comprehensive **Healthcare Analytics Dashboard** built using **Microsoft Power BI** to analyze hospital and patient data and generate meaningful insights into **patient admissions, hospital revenue, medical conditions, and doctor performance**.

The project transforms healthcare data into an interactive business intelligence dashboard that helps users explore key healthcare metrics, identify trends, and understand hospital performance.

## 📌 Project Overview

Healthcare organizations generate large amounts of patient and hospital data. However, raw data can be difficult to interpret without effective visualization and analytics.

This project uses **Power BI and DAX** to transform healthcare patient data into an interactive dashboard containing key performance indicators, trends, revenue analysis, medical-condition insights, and advanced analytical visualizations.

### Main Areas Analyzed

* 👥 Patient admissions
* 🏥 Hospital performance
* 💰 Hospital revenue
* 🩺 Medical conditions
* 👨‍⚕️ Doctor performance
* 📈 Admission trends
* 📊 Year-over-year growth
* 🔍 Advanced analytics

# 📊 Dashboard Pages

The dashboard is organized into **four analytical pages**.

## 1️⃣ Hospital Overview

Provides a high-level overview of the healthcare dataset.

### Key Metrics

* Total Patients
* Total Revenue
* Average Patient Age
* Patient Admission Trends
* Revenue Overview

This page provides a quick understanding of the overall hospital performance.

---

## 2️⃣ Patient Analytics

Focuses on patient-level and admission-related analysis.

### Analysis Includes

* Patient admission trends
* Patient demographics
* Medical condition distribution
* Patient-related KPIs
* Admission patterns

This section helps identify patterns in patient activity and hospital admissions.

---

## 3️⃣ Hospital Insights

Provides deeper insights into hospital operations and financial performance.

### Key Analysis

* Hospital revenue breakdown
* Medical condition analysis
* Hospital-level insights
* Revenue trends
* Year-over-year growth

The page helps users understand how different healthcare factors contribute to overall hospital performance.

---

## 4️⃣ Advanced Analytics

Provides advanced analytical capabilities using Power BI.

### Key Feature

🔍 **Decomposition Tree**

The decomposition tree allows users to break down healthcare metrics across different dimensions and explore the factors contributing to the selected metric.
